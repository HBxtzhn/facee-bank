这是GC按回收范围划分的四种类型，不同收集器支持的GC类型不一样。

## 1. Young GC（Minor GC）

- **回收范围**：只回收新生代（Eden + S0/S1）

- **触发条件**：Eden区满了，分配新对象放不下

- **特点**：频率高，速度快，STW时间短

- **所有分代收集器都有**

## 2. Old GC（Major GC）

- **回收范围**：只回收老年代

- **触发条件**：老年代空间不足

- **特点**：速度慢，STW时间长，频率低

- **注意**：实际中单独的Old GC很少见，很多时候Old GC会伴随一次Young GC，所以常和Full GC混淆

## 3. Full GC

- **回收范围**：整个堆——新生代 + 老年代 + 方法区

- **触发条件**：

    - 老年代空间不足

    - 元空间不足

    - 显式调用System.gc()

    - CMS的concurrent mode failure

    - 新生代晋升担保失败

- **特点**：速度最慢，STW时间最长，对业务影响最大，调优重点就是减少Full GC

## 4. Mixed GC（混合GC）

- **回收范围**：整个新生代 + 部分老年代Region

- **专属收集器**：G1收集器特有

- **触发条件**：老年代占用达到IHOP阈值（默认45%）

- **特点**：介于Young GC和Full GC之间，每次选回收价值最高的老年代Region，停顿时间可控

- G1尽量用Mixed GC代替Full GC

## 对比总结表

|GC类型|回收范围|速度|STW时长|频率|对应收集器|
|---|---|---|---|---|---|
|Young GC|新生代|快|短|高|所有分代收集器|
|Old GC|老年代|慢|长|低|CMS等|
|Full GC|整堆+方法区|最慢|最长|最低|所有分代收集器|
|Mixed GC|新生代+部分老年代|中|可控|中|G1|
