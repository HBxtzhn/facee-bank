## 追问 1：ZSET 底层为什么用跳表而不是红黑树？

① 跳表实现更简单，易于维护和调试；② 跳表支持范围查询时效率更高（找到起点后沿链表顺序遍历即可），红黑树需要中序遍历；③ 跳表的内存局部性在缓存友好度上表现更好；④ 跳表并发修改更简单（只需修改相邻节点指针）。

## 追问 2：如果排行榜数据量达到千万级，如何处理？

① 按业务维度分片（如按游戏分区、按类别）；② 使用 Redis Cluster 分散到多个节点；③ 只保留 Top N（如 Top 10000），超出部分不存储；④ 考虑使用本地缓存 + Redis 混合方案，热点数据本地缓存。

## 追问 3：如何实现"我的排名"功能？

使用 `ZREVRANK key member` 命令，时间复杂度 O(logN)，直接返回成员的排名（0-based）。如果要显示 1-based 排名，结果 +1 即可。
