## 追问 1：令牌桶和漏桶有什么区别？

漏桶以固定速率处理请求，不管进来多少请求，处理速度不变，多余的请求排队或丢弃。适合需要匀速处理的场景（比如消息消费）。令牌桶以固定速率生成令牌，有请求时从桶里取令牌，桶里有囤积的令牌时可以处理突发流量。适合允许突发但要限制平均速率的场景（比如 API 限流）。

## 追问 2：实际项目的限流是怎么做的？

三层限流：第一层在网关（Gateway）做入口限流，限制每个 API 的总 QPS；第二层在应用层用 Sentinel 做细粒度限流，按接口、按用户、按参数限流；第三层在数据库层做连接池限制。大促期间还会提前做全链路压测，根据压测结果调整限流阈值。

## 追问 3：限流和降级的关系？

限流是限制入口流量，超出的请求被拒绝。被拒绝的请求可以走降级逻辑（返回友好提示、缓存数据）。限流是"控制输入"，降级是"处理被拒绝的请求"。两者配合使用：限流保护系统不被压垮，降级保证被拒绝的用户体验。
