## 追问 1：网关能做哪些事情？

核心功能：路由转发（根据 URL 路径转发到对应服务）、负载均衡（选择后端实例）、鉴权认证（JWT/OAuth2）、限流熔断（保护后端服务）、日志监控（记录请求日志和耗时）。高级功能：协议转换（HTTP → RPC）、灰度路由（按用户/比例路由到不同版本）、跨域处理、请求/响应改写、缓存。

## 追问 2：网关挂了怎么办？

网关必须做高可用部署。至少两个节点，前面挂负载均衡（Nginx/SLB）。Nginx 用 Keepalived 做主备。网关本身无状态，可以随时水平扩展。生产环境还要做健康检查和自动扩缩容（K8s HPA）。

## 追问 3：网关层的限流和应用层的限流有什么区别？

网关层限流是粗粒度的，限制整个系统或某个 API 的总流量，是系统的第一道防线。应用层限流是细粒度的，可以按用户、按参数、按业务维度做更精确的限流。两者配合使用：网关层挡住大部分异常流量，应用层做精细化控制。
