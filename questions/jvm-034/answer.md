Java中有三类常量池，分布在不同位置，作用各不相同：

## 1. Class文件常量池（静态常量池）

- **位置**：编译后的`.class`文件里

- **内容**：存放编译期就能确定的字面量和符号引用

    - 字面量：字符串、基本类型常量值

    - 符号引用：类和接口的全限定名、字段名和描述符、方法名和描述符

- **作用**：类加载时，这些内容会被加载到运行时常量池中

## 2. 运行时常量池（Runtime Constant Pool）

- **位置**：方法区（元空间）里

- **内容**：类加载后，把Class文件常量池的内容加载进来，再加上解析后的直接引用

- **特点**：动态性——运行期间也可以把新常量放入池中，最典型的是 `String.intern()` 方法

- 每个类对应一个运行时常量池

## 3. 字符串常量池（String Pool）

- **位置**：Java7及以后在堆里，Java6及之前在永久代

- **内容**：全局共享的字符串对象缓存池，只存字符串对象的引用

- **作用**：字符串复用，避免重复创建相同内容的字符串，节省内存

- **核心方法**：`String.intern()` —— 如果池中已有该字符串就返回引用，没有就加入池中再返回

## 字符串常量池工作示例

```java
String s1 = "abc";          // 直接在字符串常量池创建
String s2 = "abc";          // 复用常量池中的对象
System.out.println(s1 == s2); // true，同一个引用

String s3 = new String("abc"); // 在堆上创建新对象
System.out.println(s1 == s3);  // false，不同对象

String s4 = s3.intern();       // 把字符串加入/查找常量池
System.out.println(s1 == s4);  // true，返回常量池引用
```
