## 追问 1：Lettuce 为什么是线程安全的？

Lettuce 基于 Netty 的 NIO 模型，底层使用一个共享的 TCP 连接（或多个连接），通过事件驱动的方式处理命令响应。命令的发送和响应是异步的，Netty 的 EventLoop 保证了线程安全，因此多个线程可以共享同一个连接而无需同步。

## 追问 2：Redisson 的分布式锁是如何实现的？

基于 Redis 的 `HSET` 实现可重入锁，key 为锁名，field 为线程标识，value 为重入次数。使用 Lua 脚本保证加锁/解锁的原子性。通过 WATCHDOG 机制（默认30秒，每10秒续期）防止锁过期后被误删。支持 Pub/Sub 监听锁释放事件，实现阻塞等待。

## 追问 3：如何选择 Redis 客户端？

简单场景用 Lettuce（Spring Boot 默认，性能好，线程安全）；需要分布式锁、分布式集合等高级功能用 Redisson（开箱即用）；老项目或简单脚本用 Jedis（API 简单，文档丰富）。不建议混用多个客户端。
