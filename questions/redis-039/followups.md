## 追问 1：如果大量 key 同时过期会发生什么？如何避免？

大量 key 同时过期会导致：① 定期删除压力增大，CPU 占用升高；② 内存突然释放后可能触发内存碎片整理；③ 若同时有大量请求访问这些过期 key，惰性删除也会增加负载。避免方式：过期时间加随机值，分散过期时间。

## 追问 2：定期删除为什么限制扫描时间为 25ms？

避免定期删除长时间占用主线程，影响正常命令处理。25ms 是一个经验值，在保证及时清理过期 key 的同时，不会对正常请求造成明显延迟。

## 追问 3：Redis 的过期精度是多少？为什么？

Redis 过期时间精度为毫秒级（`PEXPIRE`），但实际过期判断在定期删除和惰性删除时进行，因此存在毫秒级的误差。定期删除每 100ms 执行一次，所以 key 可能在过期后最多 100ms 才被主动删除（惰性删除可在访问时立即删除）。
