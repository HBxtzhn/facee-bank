判断对象是不是垃圾（可回收）有两种主流算法：**引用计数法**和**可达性分析算法**，HotSpot用的是后者。

## 1. 引用计数法（Reference Counting）

**原理**：每个对象有一个引用计数器，被引用+1，引用失效-1，计数为0就是垃圾。

**优点**：实现简单，判定效率高
**致命缺点**：解决不了循环引用问题

```java
// 循环引用示例：两个对象互相引用，外部都没有引用了
// 但各自的引用计数都是1，永远不会被判定为垃圾
objA.instance = objB;
objB.instance = objA;
objA = null;
objB = null;
```

**使用情况**：Python、PHP等在用，主流JVM都不用

## 2. 可达性分析算法（Reachability Analysis）

**原理**：从一组叫"GC Roots"的根对象出发，沿着引用链往下搜索，能走到的对象就是存活的，走不到的就是垃圾。

**GC Roots包含哪些对象？**

1. 虚拟机栈（栈帧局部变量表）中引用的对象

2. 本地方法栈JNI引用的对象

3. 方法区中类静态变量引用的对象

4. 方法区中常量引用的对象

5. 所有被synchronized持有的对象

6. JVM内部的一些基础数据结构引用的对象

**优点**：能解决循环引用问题，准确可靠
**使用情况**：HotSpot、J9等主流JVM都用这个

## 两种算法对比

|维度|引用计数法|可达性分析|
|---|---|---|
|循环引用|无法解决|可以解决|
|判定速度|快，实时增减|慢，需要遍历引用链|
|实现复杂度|简单|复杂，需要找出所有GC Roots|
|主流JVM使用|否|是|
