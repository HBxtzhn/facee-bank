## 追问 1：集群限流的 Token Server 挂了怎么办？

Token Server 挂了，Client 会自动降级到单机限流模式（用本地配置的单机阈值限流）。这样限流精度会下降（从集群精确降到单机近似），但至少不会完全失去限流保护。生产环境建议 Token Server 做主备部署，减少挂掉的概率。

## 追问 2：集群限流的性能开销大吗？

有一定的网络开销，Client 每次需要令牌时都要跟 Token Server 通信。但 Sentinel 做了优化——Client 可以批量申请令牌（一次申请多个，本地缓存），减少网络通信次数。实际测试，批量模式下性能开销在 5% 以内。如果集群规模不大（10个实例以内），单机限流就够用了，不需要集群限流。

## 追问 3：你的项目里用了集群限流吗？

用了。 API 网关（Gateway）层用了集群限流，限制每个 API 的总 QPS。Token Server 是独立部署的，用 Nacos 做高可用。应用层用单机限流就够了，因为每个实例的流量相对均匀。大促期间会根据压测结果调整集群限流的阈值。
