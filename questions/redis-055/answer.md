- **布隆过滤器原理**：一种空间效率极高的概率型数据结构，用于判断元素"一定不存在"或"可能存在"。由位数组 + 多个哈希函数组成。
- **Redis 实现方式**：
  1. **RedisBloom 模块**（推荐）：官方模块，提供 `BF.ADD`、`BF.EXISTS`、`BF.MADD`、`BF.MEXISTS` 等命令。
  2. **手动实现**：使用 String + 多个哈希函数模拟位数组（不推荐，复杂度高）。
- **核心参数**：
  - 预期元素数量（capacity）
  - 误判率（error rate），如 0.01 表示 1%
  - 底层自动计算位数组大小和哈希函数个数
- **典型应用**：缓存穿透防护、垃圾邮件过滤、URL 去重。

## 扩展知识

**RedisBloom 模块命令详解**：
- `BF.RESERVE key error_rate capacity`：创建布隆过滤器
- `BF.ADD key item`：添加元素
- `BF.EXISTS key item`：判断元素是否存在
- `BF.MADD key item1 item2 ...`：批量添加
- `BF.MEXISTS key item1 item2 ...`：批量判断

**布隆过滤器的数学原理**：
- 位数组大小：`m = -(n * ln(p)) / (ln2)^2`，其中 n 为元素数量，p 为误判率
- 哈希函数个数：`k = (m/n) * ln2`
- 例如：100万元素，1% 误判率 → 约 958万位（~1.14MB），7个哈希函数

**布隆过滤器的局限**：
- 不支持删除（可用 Counting Bloom Filter 解决，但空间翻倍）
- 存在误判（false positive），不存在漏判（false negative）
- 元素越多，误判率越高
