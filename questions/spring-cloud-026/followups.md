## 追问 1：服务端负载均衡和客户端负载均衡有什么区别？

服务端负载均衡（Nginx）：请求先到负载均衡器，再由负载均衡器转发到后端服务器。多一次网络跳转，但客户端不需要知道后端服务器列表。客户端负载均衡（Ribbon/LoadBalancer）：客户端从注册中心拿到服务列表，在本地选一个实例直接调用。少一次网络跳转，性能更好，但客户端需要维护服务列表。

## 追问 2：四层负载均衡和七层负载均衡有什么区别？

四层负载均衡工作在传输层，基于 IP+端口转发（TCP/UDP），不解析应用层协议，性能高但功能少。七层负载均衡工作在应用层，可以解析 HTTP 协议，根据 URL、Header、Cookie 等做路由，功能丰富但性能相对低。Nginx 既能做四层也能做七层。

## 追问 3：负载均衡会不会成为单点故障？

会，所以要做高可用。Nginx 一般用 Keepalived + VIP（虚拟IP）做主备，主 Nginx 挂了 VIP 漂到备 Nginx。F5 等硬件负载均衡器本身是双机热备。客户端负载均衡不存在这个问题，因为负载均衡逻辑在客户端，没有中心化的负载均衡器。
