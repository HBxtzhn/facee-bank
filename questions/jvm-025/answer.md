JVM（Java虚拟机）是执行Java字节码的虚拟计算机，整体由**五大核心模块**组成：

1. **类加载子系统（Class Loader Subsystem）**

    - 负责把.class字节码文件加载到内存中

    - 完整流程：加载 → 验证 → 准备 → 解析 → 初始化 五个阶段

    - 采用双亲委派模型，保证核心类的安全性和唯一性

2. **运行时数据区（Runtime Data Area）**

    - JVM运行时的内存布局，分为线程私有和线程共享两部分

    - 线程私有：程序计数器、虚拟机栈、本地方法栈

    - 线程共享：堆（Heap）、方法区（Method Area / 元空间）

3. **执行引擎（Execution Engine）**

    - 真正执行字节码指令的核心部件

    - 包含三部分：解释器（逐条解释执行）、JIT即时编译器（热点代码编译为机器码）、垃圾回收器（GC）

4. **本地方法接口（JNI - Java Native Interface）**

    - 允许Java调用C/C++等底层本地方法

    - 对接操作系统原生能力，拓展Java的功能边界

5. **本地方法库（Native Libraries）**

    - 操作系统层面的C/C++函数库

    - 被JNI调用，提供底层实现支撑

## 扩展知识：JVM整体工作流

Java代码的完整执行链路：

1. `.java` 源码 → javac编译 → `.class` 字节码

2. 类加载子系统把字节码加载到运行时数据区

3. 执行引擎把字节码翻译为平台机器码执行

4. 执行过程中GC自动回收堆中垃圾对象

5. 需要底层能力时通过JNI调用本地方法库
