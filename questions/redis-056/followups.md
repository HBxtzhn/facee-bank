## 追问 1：HyperLogLog 的 0.81% 误差在实际业务中可以接受吗？

大多数业务场景可以接受。UV 本身就是近似指标（同一用户换设备、清缓存等都会影响），0.81% 的误差远小于业务本身的波动。如果确实需要精确值，可以结合 SET 做小数据量精确统计 + HyperLogLog 做大数据量趋势分析。

## 追问 2：如何用 HyperLogLog 统计每小时/每天的 UV？

按时间维度设计 key：`uv:hour:2026072314`（每小时）、`uv:day:20260723`（每天）。使用 `PFADD` 添加用户，`PFCOUNT` 获取当日 UV。需要多日合并时用 `PFMERGE`。

## 追问 3：Bitmap 和 HyperLogLog 怎么选？

如果用户 ID 是连续整数且范围可控（如百万级），Bitmap 精确且高效；如果用户 ID 是字符串或范围极大（如十亿级以上），HyperLogLog 更合适，因为固定 12KB 内存不受数据量影响。
